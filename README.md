# Grant Repayment AI

Болжау аналитикасы мен жасанды интеллект алгоритмдері негізінде мемлекеттік білім гранттарын өтеу үдерістерін басқаруға арналған интеллектуалды қосымша.
Жүйе грант алған түлектердің өтеу міндеттемесін бақылайды, төлемді кешіктіру тәуекелін болжайды және мамандарға шешім қабылдауға көмектеседі.

## Мақсаты
Мемлекеттік білім гранттарын өтеу үдерісін автоматтандыру және ЖИ көмегімен міндеттемені орындамау тәуекелін алдын ала анықтау.

## Пайдаланушылар
- Грант алушы (түлек)
- Өтеу жөніндегі маман
- Талдаушы
- Әкімші

## Талаптар
1. Грант алушы жүйеге кіріп, өз грант міндеттемесі туралы ақпаратты қарайды.
2. Грант алушы жұмысқа орналасу немесе өтеу жоспарына өтінім береді.
3. Жүйе өтінімдегі деректердің дұрыстығын тексереді.
4. Жүйе ЖИ моделі арқылы өтеуді кешіктіру тәуекелін болжайды.
5. Маман өтінімді қарап, бекітеді немесе қабылдамайды.
6. Жүйе грант алушыға өтінім күйі туралы хабарлама жібереді.
7. Талдаушы болжау нәтижелері мен өтеу статистикасын есеп түрінде қарайды.
8. Әкімші пайдаланушыларды және жүйе баптауларын басқарады.
